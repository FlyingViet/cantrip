# Keyboard shortcuts

## macOS

| Keys | Action |
|---|---|
| **Option+Space** | Show or hide Cantrip |
| **Option+Shift+Space** | Capture selected text from the front app and open Cantrip |
| **Return** | Launch the selected app suggestion, or submit a prompt; while busy, use Auto unless a delivery override is selected |
| **Command+Return** | Send to AI instead of the app suggestion; while busy, interrupt and redirect |
| **Option+Return** | Inject a follow-up into an active Claude Code turn |
| **Command+T** | New local session |
| **Command+N** | Reset the current local conversation |
| **Command+W** | Close the current local tab |
| **Command+1** | Select the pinned Remote tab |
| **Command+2** through **Command+9** | Select local sessions, starting with the first at Command+2 |
| **Command+Shift+[** / **Command+Shift+]** | Previous/next tab |
| **Command+Left/Right** | With input text: move to start/end; with an empty editor: switch tabs |
| **Command+Shift+Left/Right** | Extend selection to the start/end of the input |
| **Command+V** | Paste text, or attach a supported clipboard image/file |
| **Escape** | Hide panel and overlays; does not cancel a run |
| Terminal **Up/Down** | Browse command history |
| Terminal **Control+C** | Interrupt the active manual command or agent run |

`Option` is the key marked `option` or `alt`; `Command` is the key beside the
spacebar marked with the command symbol. Shortcuts for local sessions do not
describe controls inside the embedded Remote web client.

## Windows

| Keys | Action |
|---|---|
| **Alt+Space** | Show/hide Cantrip |
| **Ctrl+Space** | Fallback when Alt+Space is unavailable |
| **Enter** | Submit or launch the selected app |
| **Ctrl+Enter** | Force an AI prompt instead of launching the selected app |

## Prefixes are commands, not shortcuts

| Prefix | Meaning |
|---|---|
| `!command` | Run a shell command directly (PowerShell on Windows) |
| `/skill args` | Run an installed executable skill (Mac only) |

These commands execute as you. Review unfamiliar commands before pressing
Return/Enter.
