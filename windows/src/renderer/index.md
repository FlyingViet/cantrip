# Renderer Index

| File | Purpose |
|------|---------|
| `renderer.ts` | Keyboard-first launcher state and interactions |
| `styles.css` | Transparent Windows launcher presentation |
| `global.d.ts` | Typed preload API declaration |
| `vite-env.d.ts` | Vite asset and CSS module declarations |
| `cards.ts` | Generic card renderer: draws card documents (`docs/cards.md`) block by block |
| `cards.css` | Card styles, shared by the launcher and the Cantrip Home window |
| `home.ts` | Cantrip Home window: Home, Background (+ Full Log) and Tasks from the paired Mac |
| `home.css` | Cantrip Home window presentation |
